Build it in Shortcuts

  1. Create a new Shortcut.
  2. Add a Text action and paste a test BBK SMS message that contains BHD.
  3. Add Get Contents of URL.
  4. Set the URL to the import URL above.
  5. Set Method to POST.
  6. Add the header ngrok-skip-browser-warning with value true.
  7. Add the header X-API-Key with the API key shown above.
  8. Set Request Body to JSON or Form.
  9. Add raw_message and connect it to the Text action.
  10. If JSON/Form is confusing, send the received message as raw text body instead.
  11. Run the Shortcut, then check the Transactions page.
